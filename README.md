Hello, I live in Astoria, NY. When I walk to school, I pass by many houses, stores, and restaurants and I often see a lot of garbage outside the buildings to be picked up. This is so much waste! This made me wonder if some of this garbage could be re-used by someone else. So, what if we could make Astoria's businesses work like an ecosystem, where someone’s waste becomes the other’s resource?
 
For example, grocery stores sometimes throw away food that could be donated before it expires. Restaurants throw away leftover food that can be used for soil and gardening. Stores throw out boxes that can be used by moving companies. Coffee shops throw out coffee grounds that can be used as compost by community gardens. Construction companies throw out leftover wood that can be used by carpenters or schools for student projects. 

This gave me the idea of creating this app and call it Astoria Circular Exchange. Instead of waiting for something to become garbage and pollute the environment, this app will try to find another local business that can use it. So, let me show you how it works.
 
You can visit the website and create an account and indicate the type of business you are. Then, you can add the information for the exchange. 

1.    The material type that you will give away, the amount, and the time for pickup
2.    The material type that you want to get, the amount, and the time for pickup.

Then, the app will use this information from all the businesses that sign up and match you with the best possible partner. But the next question is how does it do it? How can it find the best partner? 
 
So, the algorithm will choose the match that can get the highest points. The total points are 100. 
Material fit can get up to 40 points 
Amount fit can get up to 20 points 
Delivery time can get up to 20 points 
Distance can get up to 20 points

 
There are still questions that I need to work on. For example, how do I know the best way to calculate the material fit or distance? One example is like this: 0-1 mile distance gets all 20 points, distance 1- 2 miles distance gets 10 points, distance 2-3 miles gets 5 points, and more than 3 miles gets 0 points.
